# CRT PowerShell

A PowerShell-style terminal on a glowing monochrome CRT, with scanlines and a power button.

![CRT PowerShell screenshot](<CRT PowerShell - screenshot.png>)

## Commands

| Command | What it does |
|---|---|
| `help` | Show the command list |
| `dir` / `ls` | List files |
| `cls` / `clear` | Clear the screen |
| `echo <text>` | Print text |
| `whoami` | Show the current user |
| `date` | Show the date and time |
| `color <name>` | Change the phosphor: green, amber, blue or white |
| `history` | Show command history (Up and Down arrows work too) |
| `exit` | Close the session |

## Run it

Download `crt_powershell.html` and open it in your web browser. No install, no account, nothing to set up.
